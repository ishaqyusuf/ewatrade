## What it does

`inventory.package.transform` (`stock_package_transform`) drafts a signed,
reviewed repack between two different existing PACKAGED_STOCK balances of the
same Store, Product and variant, for example opening crates into single
units.

- **Quantity:** only `sourceQuantity` is drafted. The target is derived
  exactly as source × sourceFactor ÷ targetFactor, using `parseExactDecimal`,
  `multiplyExactDecimals` and `divideExactDecimals` at the target unit's
  transaction scale. Nothing is rounded and no model target is accepted.
- **Refusals:**
  - a source amount not representable in its unit;
  - a target not representable ("does not make whole <unit>" only when the
    target scale is 0, otherwise "cannot be represented in <unit>");
  - zero target;
  - the same balance twice;
  - a balance that is not packaged stock;
  - a different Product or variant;
  - different configuration versions;
  - more than on hand minus reserved;
  - a foreign or other-Store balance (generic unavailable, no disclosure).
- **Review lines:**
  - Store, Product and variant, both pack units with factors, and the
    conserved canonical quantity;
  - source on hand → after, reserved and available;
  - target on hand → after and reserved;
  - "Record any loss as a separate adjustment". No linked adjustment is
    created.

## Binding and confirmation

The signed digest covers:
- Store, Product/variant and configuration version;
- for both balances: ID, revision, unit, factor, scale, on hand and reserved
  (plus available for the source);
- source and target quantities and the canonical quantity.

Any change makes the draft stale.

`prepareExecution` runs in this order:
1. review;
2. `lockInventorySourcesForReview` (financial Store first, then both sorted
   balances);
3. re-review;
4. `transformPackagedStockInTransaction` inside the proposal transaction,
   with clientOperationId = proposal key, `source: "assistant"`, both
   revisions, the expected configuration version and both quantities.

The receipt is `inventory`, "Stock repacked".
