12 October 2026. D05/S04/G03 source integration, reviewed by root after three
implementation-worker handoffs. Parents remain partial and unbookmarked:

## Result

Five strict GENERAL intentions now register their existing prepared/native adapters:
assign a Job, change its promise, transition an exact Line, record a private note,
and record an open exception. Dedicated dashboard editing loads real eligible
assignees and fixed saved Job/Line context, then refreshes context and pure review
before updating the draft. App confirmation remains separate. A list exceeding
100 eligible assignees is explicitly incomplete and cannot enable assignment.

The protected query-only serviceAssistantWork router exposes editorContext, review
and original. Each query derives authority from the session and uses a bounded
caller-owned RepeatableRead transaction. Prepared commercial work refuses actual
PRESCRIPTION_REQUEST quote origin, clinical pickup/address links and prescription
payment-intent links before projecting work or preparing confirmation. The existing
administrative/legacy Manager ceiling remains; scoped Manager grants are not added.

Original event/note/exception identities survive strict completed receipts, saved
answers and URL dispatch. Three global sheets show original Service work, original
quotation approval/version and saved booking in the dashboard shell. Opening and
closing use shallow object parameters; current Job navigation is a separate button.
Their query keys include authenticated actor/Tenant/Store plus the complete original
tuple. Typed tRPC queries forward cancellation; empty scope, pending/fetching/paused,
failed, pre-mount or wrong-original responses withhold object content. tenant.current
adds the authenticated actorUserId projection; scope is never accepted as wire input.
Original exception creation outcome is explicitly unknown when not immutably saved.

S04 access review now includes an exact current-assignee outstanding-work count plus
ten bounded Job details from one SQL statement. It counts Jobs with at least one
non-completed/non-cancelled Line, includes same-business archived Stores, and makes
no performed-work or handover claim. Only the observation timestamp is excluded
from its review digest; changes to actual workload still invalidate the review.

Eleven new dashboard capabilities and their tools are registered as planned.
Natural-language instructions resolve native identities and real staff choices;
pending quotation pagination reports visible page counts rather than queue totals.
No capability or persistent runtime configuration was activated.
