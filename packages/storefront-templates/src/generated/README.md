# Reviewed component source

`public-intro@1.0.0` is the exact reviewed offline fixture artifact recorded in
`public-intro/review.json`. Source, manifest and CSS are byte-identical snapshots;
the focused promotion test verifies those hashes and the current SDK hash. Narrow
Biome import-order/manifest/CSS formatting exceptions preserve those bytes. Source
lint and normal formatting for the trusted host and registry remain enabled.

Only the reviewed TSX source enters the static application import graph. The
qualification bundle, raw generator output and artifact HTML are never evaluated
or injected by the application. The host projects current public business facts,
theme and allowed typed actions through the existing runtime/server authority.

`component-editorial@1.0.0` is an opt-in registry entry using this introduction and
the existing editorial collection. Catalog v4 remains the default. Composition
selection and AI proposals save ordinary validated data; publication and rollback
use the existing scoped SiteRelease commands. Local qualification does not claim
deployment. A future release uses the ordinary authorized platform code pipeline.

To promote another component, inspect its immutable ready artifact and provenance,
review exact source plus the inert fixture outputs, copy the accepted source and
manifest/CSS with their hashes, add explicit component/template pins and static
renderer dispatch, then run the targeted build and ordinary composition/lifecycle
checks. Failed, unreviewed and rejected artifacts remain outside this directory.
Never load a renderer from an artifact path or substitute a latest version.
