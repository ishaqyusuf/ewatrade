# Product creation uses registration-owned Terms

Catalog no longer asks existing merchants to accept Terms again when adding or
editing products/services. Setup and focused product chat remove the duplicate
agreement panel; old blocked drafts can be retried without losing their data.
Registration retains explicit agreement and its versioned receipt. Authorization,
Catalog content screening, validation and transactional confirmation are retained.

Validation: 19 focused tests/52 assertions; Dashboard TypeScript; scoped Biome.
Release target: Production only. Live replay acceptance is tracked in the project
Brain launch/catalog-terms-production-2026-10-09.md receipt. No schema migration.
