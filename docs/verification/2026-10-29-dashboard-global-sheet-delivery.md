## Confirmed cause and change

After hydration, GlobalSheets statically imported41 feature controllers and their
heavy content graphs regardless of URL intent. A mounted test of the actual factory
reproduced48 failures: ordinary navigation mounted every family, while a deep link
also mounted unrelated families. Presentation/transport are inert; the actual
factory, canonical parsers, React lifetimes and access/path conditions run.

All41 global imports now use existing next/dynamic behind ActivatedSheet. Typed URL
parsers/allowlists drive delivery hints only; existing child read/command checks
remain authoritative. A loaded controller remains mounted through close/reopen in
the same actor/Tenant/Store, allowing its existing body gates, dismissal, focus,
draft/lock and invalidation owners to work. Scope keys reset activation; current
permission/path gates still remove subtrees. Late imports cannot resurrect an old
scope. Pending requested code shows Opening…; closing hides that feedback even if
the chunk is still arriving. No payload freshness, retention or query key changed.

Pure assistant object URL constants moved out of receipt orchestration; the original
hook reexports them for compatibility. Enum/array parsers are shared with actual
controllers, not a second raw-URL decoder. Empty malformed original-target flags
still activate their current refusal owner. An audit caught the recorded-order
message offer outside the message sheet: it also activates its controller, without
opening/sending a message. Its regression first failed, then passed after correction.

Midday's global provider/URL hooks informed ownership and thin orchestration;
React/Next demand imports supply the additional delivery boundary. Midday's static
factory itself is not evidence that all imports should remain eager, nor is any
Midday-versus-EwaTrade benchmark claimed. Existing UI/forms/headers/sheets remain.
