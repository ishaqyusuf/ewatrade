## Stage Definitions

- `Queued`: inventory exists; current-program baseline is not yet captured.
- `Baseline captured`: exact current native screen is archived.
- `Directions ready`: five HTML/PNG options and comparison board exist.
- `Awaiting owner approval`: selector-enabled batch and recommendation are
  ready; production source remains untouched.
- `Selected`: strongest option and rationale are recorded.
- `Implemented`: approved direction is in production source.
- `Native QA`: implementation is being exercised on the emulator.
- `Complete`: all applicable functional, visual, theme, text, keyboard, state,
  evidence, and Brain gates pass.
